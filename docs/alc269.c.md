## Developer Track

### What This File Does (Upstream)
`alc269.c` is the Realtek ALC269 High Definition Audio (HDA) codec driver in the Linux kernel. It parses hardware pin routing, maps mixer controls, and applies laptop-specific model quirks (such as GPIO settings and pin configurations) to ensure proper audio output.

### What The Patch Changes

The patch overrides the hardware output amplifier capabilities on the internal speaker (Pin NID `0x14`) and headphone (Pin NID `0x21`) widgets to shift their 0dB reference points and bypass the motherboard-level power clamp.

**Key Implementations:**

1. **Enum Member (`ALC269_FIXUP_KING_KONG`):**
   ```c
   ALC269_FIXUP_KING_KONG, /* GORILLA: +60dB amp override for Sony VAIO */
   ```
   Inserted into the Realtek HDA fixup enum block.

2. **Amplifier Override Function (`alc269_fixup_king_kong`):**
   ```c
   static void alc269_fixup_king_kong(struct hda_codec *codec,
                      const struct hda_fixup *fix, int action)
   {
       static const hda_nid_t nids[] = { 0x14, 0x21 };
       u32 caps;
       int i;

       if (action != HDA_FIXUP_ACT_PRE_PROBE)
           return;

       for (i = 0; i < ARRAY_SIZE(nids); i++) {
           caps = query_amp_caps(codec, nids[i], HDA_OUTPUT);
           if (caps) {
               caps &= ~AC_AMPCAP_OFFSET;
               caps |= (0x04 << AC_AMPCAP_OFFSET_SHIFT);
               if (snd_hda_override_amp_caps(codec, nids[i], HDA_OUTPUT, caps))
                   codec_warn(codec, "ALC269: failed to override amp caps for NID 0x%x\n", nids[i]);
           }
       }
       codec_info(codec, "ALC269: KING KONG ROAR (+60dB) unleashed!\n");
   }
   ```
   Queries the default amplifier capabilities using `query_amp_caps`. If cached capabilities exist, it clears the baseline offset (`AC_AMPCAP_OFFSET`) and updates it to `0x04`. It then calls `snd_hda_override_amp_caps` to lock the new ceiling, checking for return failures and printing warning logs.

3. **Fixup Struct Chain:**
   ```c
   [ALC269_FIXUP_KING_KONG] = {
       .type = HDA_FIXUP_FUNC,
       .v.func = alc269_fixup_king_kong,
       .chained = true,
       .chain_id = ALC269_FIXUP_SONY_VAIO,
   },
   ```
   Registers the fixup function and chains it to `ALC269_FIXUP_SONY_VAIO`. This ensures the card applies standard pin layout setups (like pulling VREFGRD on `0x19`) before running the custom amplifier capability override.

4. **Quirk Redirection:**
   ```c
   SND_PCI_QUIRK_VENDOR(0x104d, "Sony VAIO", ALC269_FIXUP_KING_KONG),
   ```
   Redirects the quirk table matching PCI Vendor ID `0x104d` (Sony) to apply `ALC269_FIXUP_KING_KONG` instead of standard Sony VAIO fixups.

## Layman Track

### What Does `alc269.c` Normally Do?

Your laptop has a physical sound chip (the Realtek ALC269) that converts digital sound waves from the browser or media player into electrical signals for the speakers.

To prevent the speakers from blowing out or causing the laptop chassis to vibrate, the laptop motherboard has a physical power clamp that limits the maximum output volume. Because the ALC269 is naturally low-powered, this clamp makes the laptop speakers extremely quiet.

Normally, the driver parses the hardware and enforces this physical volume ceiling.

### What The Patch Does

This patch is the **"KING KONG ROAR" (+60dB) amplifier unlock**.

It intercepts the sound chip's initialization process and **overrides the physical amplifier limit** on two specific lines:
- The internal speakers (pin `0x14`)
- The headphone jack (pin `0x21`)

It clears the chip's default maximum sound limit and programs a much higher hardware ceiling (setting the offset shift register value to `0x04`).

This forces the motherboard to feed maximum power to the speakers, bypassing the default soft limits and boosting maximum volume by up to **+60dB**.

### Who Benefits

Sony VAIO laptop owners who find their speakers quiet or hard to hear at 100% volume will get an immediate, massive physical volume boost.

### Trade-Offs

- **Speaker Rattling:** At absolute maximum volume, the physical plastic keyboard and chassis of the laptop may vibrate or rattle.
- **Dynamic Limiting:** In software (PipeWire/AudioStream.cpp), we use a software compressor/limiter (`FastTanh`) to smooth out peaks, preventing hardware blowout while keeping the physical hardware amplifier fully saturated.
